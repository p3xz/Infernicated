How it works

Local first, honest always

  1. You type. The password lives only in the input field and in memory while the page is open.
  2. It is scored locally. Length, character pools, repeated runs, sequential and keyboard patterns, and a list of common passwords are all checked in JavaScript, in your browser.
  3. Breach exposure uses k-anonymity. The password is hashed with SHA-1 locally; only the first five hash characters are sent to Have I Been Pwned, and the suffix match happens on your device.
  4. Nothing is stored. No backend, no database, no analytics on what you typed. Close the tab and it is gone.

A high score means the password is hard to guess, not that it is safe to reuse. Use a unique password for every account, ideally kept in a password manager.
